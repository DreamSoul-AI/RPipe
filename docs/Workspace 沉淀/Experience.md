# 三、建议 workspace 研发入口配套外部路径脚本

**状态**：待讨论；本地workspace研发模板暂无该专门入口，本轮未修改上游、提issue或PR。

建议在研发模板旁提供可复制的外部路径配置脚本模板，由《研发用AGENTS.md》指向它。涉及大数据、权重或运行产出的项目，先确认本机真实输入、缓存及项目输出位置，再按项目职责适配访问入口；项目README记录具体命令。数据可跨项目共享，可写产出按项目隔离，机器路径显式传入，不设个人盘符默认值。

脚本模板至少支持只读预览、显式创建、正确链接重复复用、真实路径分离核验和Git忽略检查；已有目录或错误链接不覆盖、不搬运、不删除，权限与平台不支持时明确报错，不静默复制大文件或更改系统权限。脚本的放置及调用方式适配项目语言和结构，不要求项目运行时依赖workspace仓库，也不要求每个项目都采用同一目录布局。

RPipe的system/local_paths.py及上述CPU旅程可作为来源案例。其Windows监管要求运行树shared为实体目录是RPipe消费者约束，不直接升级为所有项目的限制；其他系统、模型路径和其他项目仍待各自验证。形成共用修改时，将来源、方法、工具、验证范围及拟改条目汇集到workspace，再按实际授权审阅及修改模板。
