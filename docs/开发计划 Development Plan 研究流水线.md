# 开发计划 研究流水线

[返回文档入口](../README.md#文档导航)

更新日期：2026年11月7日。当前目标：同步 workspace 最新规范、复核文档，按工作分支 → dev → main 的顺序集成，发布 **v0.5.1**。用户已授权本轮合并和小版本发布，取代上一阶段暂不进入 main 的停止点。

## 当前状态

- 上轮文档整理与记录已通过 #244、#245 合入 dev；本轮规范同步和版本候选通过 #246 合入 dev，main 集成由 #247 承接。
- workspace 新规范已按固定提交适配；已采用经验已保存并从本仓活动队列清理。
- 发布检查发现Windows协作取消状态异常，已确认并修复实际worker结束窗口的收尾缺口；80项相关检查通过，新候选完整CI待验证。本轮不安排额外重构、GPU实验或完整研究矩阵。
- 正式发布仍为 v0.5.0；v0.5.1 是本轮候选，实际发布后再更新状态。

## 执行顺序与验收

| 阶段 | 工作与验收 | 状态 |
| --- | --- | --- |
| 规范与文档 | 对齐共用研发模板，保留 RPipe 专有约定；逐份复核 README、docs、入口和历史来源 | 已完成本地复核 |
| 候选验证与 dev 集成 | 核文档、版本和实际包；候选自身必需检查通过，按适用确认完成工作分支 PR | #246自身9项检查通过，已合入dev |
| main 集成 | dev → main 发布 PR，核全量差异、规定发布确认及必需检查，核实际 main 提交 | #247已创建；#248补齐历史并修复取消收尾，须新候选CI通过后推进 |
| 产物与发布 | 从最终 main 构建 wheel／sdist，安装验证来源、版本及离线 CLI；发布 v0.5.1 和校验文件，回读下载 | 待执行 |
| 收尾 | 更新当前状态与日期记录，同步本地长期分支，清理已合并的本任务工作分支 | 待执行 |

CI 或本地构建运行时，继续独立准备发布说明、复核文档或产物清单；固定被验证来源，不把轮询和等待当作工作成果。依赖检查结果的合并与发布判断仍等结果完成，不为凑时长增加任务。

## 发布范围与验证

v0.5.1 汇集 v0.5.0 后的外部 data/output 入口配置、GitHub 文档整理及新研发约定，不承诺新增科学结论或下游兼容层。版本元数据与 CLI 一致，wheel／sdist 分别验证严格来源及 Toy/Stub 离线主流程；现有 CI 继续提供跨平台 CPU 和打包检查，保持既有失败与跳过语义。

另包含Windows取消收尾对实际worker身份的最小修复。原CI失败和本地反例分别保留，证据及归因限制见[运行记录](<运行记录 Run Record/2026-11-07 v0.5.1发布与取消收尾验证.md>)；任一新候选必需检查失败均阻断，不以其他平台通过替代。

本地检查覆盖 Markdown 解析、文件和章节链接、代码围栏保全、规范适配与必要版本回归。GitHub 实际显示与本地解析分别记录，不把静态通过写成逐页视觉验收。科学代码与协议保持原身份，无默认重跑要求。

## 依据与结束条件

[本轮记录](<开发记录 Development Record/2026-11-07 规范同步与v0.5.1发布.md>)保留规范来源、历史计划快照和实际交付结果；[项目沉淀](<Workspace 沉淀/Experience.md>)维护当前待汇集事项。workspace 修改已采用的三项要求后，本仓不再维护另一份共用正文。

结束条件：dev 和 main 实际集成且必要检查通过；v0.5.1 发布附件与最终验证产物字节一致；下载、版本和来源可核；Markdown 当前状态与实际交付一致；本地长期分支同步，未覆盖其他任务改动。既有标签与研究证据保留。

本计划冻结于发布准备阶段。最终合并、发布状态与下载验收从[v0.5.1发布页](https://github.com/DreamSoul-AI/RPipe/releases/tag/v0.5.1)及本轮记录关联的外部交付回执核对，不将本页准备状态当作发布结果。
