# 四、执行边界

RPipe是可直接修改的研究模板，保持structure/flow两柱，不新增payloads或下游兼容层。普通工程问题先保留具体反例再最小修复；职责变化更新两份设计，科学协议歧义先校准。每批依据实际影响验证并维护活动缺陷、开发记录和运行记录。

本轮允许目标分支提交、正常推送和Draft PR正文更新；不合并、不发布、不启用autoMerge，不写飞书或同步下游，不修改workflow、Actions、仓库设置或凭据。CPU预算自主设定，产物在外部根，不下载大依赖或默认启动GPU完整研究，不处理其他任务进程或旧owner。
