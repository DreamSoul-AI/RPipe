# 三、研究衔接

工程重构及测试通过不代替研究 E0–E4。正式实验前固定新代码 SHA/version、原始输入、数据与模型、算法、指标、设备与精度、依赖、seed、外部运行及归档根、资源预算和停止条件，并另行取得执行授权。历史结果不补签为重构后验证。
