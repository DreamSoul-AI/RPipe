# 二、合同与实现

control 的 RunRef 描述保存的身份、位置、seed、分组及明确训练依赖，不含执行权或源码建构。RunSpec.ref 为纯投影。artifact.io 维护实际 RunRecord/ExecutionRecord 结构及共用纯校验，读端与唯一 writer 使用同一约束，区分布尔与整数，缺少正式记录不能冒称成功。

artifact.checkpoint 接明确绝对 .pt 文件，以唯一格式和原子替换提交完整安全状态；算法决定保存与恢复策略。Flow 在构造时显式传本次和明确 train_id 对应的快照根，System 不再保存快照或携带训练目录、研究源码与 pickle reader。NumPy RNG 以明确基础状态表示，恢复时还原原数值状态，不引入任意类反序列化或目录猜配。

恢复准入前置到模型、数据、RNG、Tracker 等状态应用之前；Data 提供不建 loader、不推进 RNG 的状态校验。原生与 HF 的恢复范围分开，拒绝不支持的状态，不以文件可读宣称完整恢复。具体格式及能力见代码结构设计，实际反例和结果见运行记录。

readout 和 comparison 实际归 artifact，旧聚合门面、目录猜配、历史格式与轨迹回退退出。正式读端使用保存的身份及 schema 3 index，不导入 Flow、科学构造器或核当前源码；比较明确记录、轨迹及所选快照，研究差异报告来源与条件，不据观察相同推论科学等价。

CLI 查询显式 --version 时不需源码在场；省略时仅读声明中的版本字段定位输出，不重新生成计划。Study 汇总则核当前来源与正式清单，写出前重核 index/config/result/execution/明确 attempt outcome 及 busy 状态的指纹，变化时拒绝并保全旧汇总。Run process 严格比对保存的 JSON，单 Run 与整轮作用域保持分开。

曲线与 TensorBoard 导出只选正式清单中的 Run 和 JSONL 有效观测，不扫描历史残留。研究探针对明确的观察状态比较，保留末次指标、轨迹坐标及 latest/best 的模型、优化器和调度器门；不再伪造无正式身份的 Run 来迁就旧比较接口。
