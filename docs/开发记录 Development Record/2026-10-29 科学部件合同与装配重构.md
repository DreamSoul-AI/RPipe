capture_rng/restore_rng 的真实函数体迁到 system.runtime，与本批基线函数 AST 一致；算法内部引用和测试同步，不留旧模块转发。原生/HF 预算、更新、scheduler、early-stop、梯度累计尾批及恢复判据保留。

# 三、初始化与数据边界

configure_science 只解释声明/control 和日志构造元信息；prepare 按 runtime/RNG → System → Logger → 研究构造前准备/配方 → Data → Model → Algorithm/Tracker 落地。prepare 的逻辑阶段先明确，Logger 存在后才发相应事件。早期无科学 Logger 的错误由持权者补记；响应携带 stage/error_logged，已记录的首错不因后续关闭失败重复记录。

HF 的 dataset、batch size 和 split 查询改用 Data 正式能力，不再读 _loaders。原生默认的 iter_batches 游标路径保留；HF 显式 resumable=False，直接遍历原 loader 并登记所属迭代器，不额外重建 loader、更换 sampler/generator 或启用原生游标跟踪。开关不代表来源拥有完整恢复能力；不支持者仍返回不支持的状态观察。

保留模型端训练态 CIFAR flip → crop → Normalize → net、SVHN crop → Normalize → net，评测无随机增强；数据端原 ToTensor 位置不变。形状仍按原声明/元信息优先级和数值转换解释，合法 Linear 展平不要求 tuple 形状完全相等。补充显式 in_features 与所选输入 shape 乘积冲突拒绝，避免声明 3 却构造 2；最终仅补一致性，不额外收窄此前 0/数字字符串转换范围，也不据纯形状测试扩大科学支持。

来源/模式有默认值时仅 None 取默认；显式空名或 False 不再静默变原生训练。System 未知来源在构造输出前拒绝，显式 logger 与 logging_context 同时提供也拒绝，避免忽略其中一项。
