## 维护方式

本文件只维护尚待整理或汇集的项目经验。已有 Git 提交保存后按用户确认从队列清理；清理、workspace 接收和共用规则采用分别依据实际状态判断。历史内容从提交和日期记录追溯。

## 当前状态

2026年11月7日，本轮三项经验已由 workspace 采用，本仓已按发布基线同步，目前没有待汇集的新条目：

- **GitHub 文档规范**：README 和 docs 按 GitHub 阅读方式组织，共用正文由 workspace 维护。
- **计时任务的时间意识**：粗略规划、阶段检查、按余量调整，不拿等待充当实际工作量。
- **等待期间的独立工作**：CI/CD、Study 等任务运行时继续已授权、无结果依赖的工作，保护运行来源并考虑资源占用。
