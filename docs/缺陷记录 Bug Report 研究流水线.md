## 登记与关闭条件

新问题应记录入口、触发、期望、实际、版本／环境、影响和证据。修复后回归原反例，未执行、缺失和未知如实保留，不通过放宽科学门关闭问题。

已验证关闭的问题从活动记录移出，经过及运行证据进入日期记录。旧结果的来源限制、原件缺失和未执行实验按其原状态保留，不因没有活动缺陷就视为已解决。
